# Cat Key

### The all-in-one shortcut manager. With a cat.

Like a password manager, but for shortcuts: every shortcut of every app, on Windows and Mac, in one place. Keep them, change them, share them, borrow other people's, and train until your hands know them by heart. When you do something the long way, the cat tells you the shortcut.

<sub>Every cat walks across a keyboard. This one presses the right keys.</sub>

## What it's for

**Your hands already know the shortcuts. The apps just disagree.**

- **Switching from a Mac?** Keep your ⌘ habits on Windows. Alt sits right where ⌘ was, so Alt+C copies, Alt+W closes the tab and Alt+Q quits, everywhere. Moving to a Mac, the other way round.
- **Every app wants different keys?** Give the same keys the same job everywhere, or a different job in one app only: Premiere keys inside DaVinci Resolve, Mac keys in Excel, your own keys anywhere.
- **Learning a pro app?** Pick Premiere Pro, Resolve, Blender, Photoshop or any other app, and **Train yourself** with the shortcuts the pros use, until your fingers do them without thinking.
- **Still reaching for the mouse?** The **shortcut coach** notices when you click something that has a shortcut and shows you the keys in a little note that fades away. Cat Key adds up the time shortcuts save you, and the time the mouse costs you, app by app.
- **Want to get fast?** Climb from Kitten to **Keyboard Warrior**: every rank dresses your cat in new gear. Post your Cat Card to the leaderboard, or race your friends.

Each app keeps its own shortcuts. Cat Key only adds yours on top, and you can switch it off (or let the cat nap) any time.

## Install

### Windows

1. [Download the installer](https://github.com/MasterfullyClaw/CatKey/releases/latest/download/CatKey-Setup-x64.exe) and run it. It doesn't need admin rights.
2. Cat Key opens with your first shortcuts already working, and it lives in the tray by the clock.
3. Want shortcuts in apps that run as administrator (Task Manager, admin terminals)? Settings → **Works in admin apps** → Allow.

Prefer no installer? Grab [the portable exe](https://github.com/MasterfullyClaw/CatKey/releases/latest/download/CatKey-portable-x64.exe).

### Mac

1. [Download the disk image](https://github.com/MasterfullyClaw/CatKey/releases/latest/download/CatKey-mac.dmg), open it and drag **Cat Key** into **Applications**.
2. Open Cat Key from Applications. The first time, macOS says it can't check the app, because Cat Key isn't notarized by Apple yet. Either:
   - open **System Settings → Privacy & Security**, click **Open Anyway** next to Cat Key, then **Open Anyway** once more in the box that follows; or
   - if that keeps going round in circles, paste this into **Terminal** and press Return. It removes the "downloaded from the internet" flag from Cat Key only, and opens it:
     ```sh
     xattr -dr com.apple.quarantine "/Applications/Cat Key.app" && open "/Applications/Cat Key.app"
     ```
3. Let Cat Key use the keyboard: when macOS asks, click **Open System Settings** and switch Cat Key on under **Accessibility** (and **Input Monitoring**, if it asks). Its Checkup has a button that opens that page.

On a Mac, ⌘ is shown as ⌘ and Cat Key starts with no remaps (your Mac already has ⌘); pick what you want from the Library and Templates, like *Windows keys on a Mac* for Ctrl habits. The shortcut coach works on a Mac too: click a menu item that has a shortcut (or a window's close and minimise buttons) and a little note shows its keys.

## How it works

Cat Key listens to the keyboard with a standard Windows keyboard hook. When you press one of your shortcuts, it holds that key back and sends the one you meant instead, in under a millisecond. Everything else goes through untouched.

- **It never misses a key.** The hook only decides; a separate thread sends keys, so a slow program elsewhere can't make Windows skip Cat Key. A watchdog reads the keyboard directly and repairs a key release that went missing.
- **It doesn't fight other tools.** Keys typed by other programs (password managers, macro tools) pass untouched. Alt shortcuts work even with PowerToys Grab And Move holding Alt back.
- **It stays out of your typing.** Single-letter remaps pause while a text cursor is active, so "V does A" in an editor never turns "Very" into "Aery".
- **Your keys stay yours.** Cat Key keeps no keystroke log. For your stats it keeps only how many shortcuts you used in each app, never which keys or any text. Train yourself counts presses only for the shortcuts you're learning, on your PC. The optional key log (for troubleshooting) runs only while you have it open.
- **The coach never looks at your screen.** When you click, it asks the system what's under the pointer (UI Automation on Windows, Accessibility on a Mac: the way screen readers do) and reads only that item's name and shortcut. Chrome-based apps are left out unless you switch them on, because answering costs them a little work.

## Claude Desktop (and other AI apps) can hand packs straight to Cat Key

Cat Key is also an MCP server, the plug AI apps use for tools. In **Cat Builder**, press **Connect Claude Desktop** (it adds Cat Key to Claude Desktop's settings and keeps a backup), quit and reopen Claude Desktop, then just ask: *"Make me Cat Key shortcuts for Blender"*. Claude reads the pack format, looks up the real shortcuts and sends the pack; Cat Key opens it so you pick what to add. Claude can also read your shortcuts (read-only), so new ones don't clash. Nothing changes until you add it.

For other apps that speak MCP, **Copy the setup** gives the JSON, and **Copy for Claude Code** the line for `claude mcp add`. The server is the Cat Key program itself, started with `--mcp`.

## Make and share packs

Packs are small JSON files. The [library guide](library/README.md) explains the format. To share one, open it in Cat Key and press **Post to the store**: GitHub opens in your browser with the pack filled in (Cat Key never sees your login), and a GitHub Action lists it in everyone's *Library → Community* with your name. ❤️ on a pack's issue is a like; the store re-ranks every hour.

## Troubleshooting

- **A shortcut needs two presses.** Update to the latest version. If it still happens: Settings → *Try a shortcut* → **Start key log**, use the shortcut, then **Save**, and attach the log to an issue.
- **Alt shortcuts feel slow or odd.** PowerToys **Grab And Move** also uses Alt. Cat Key copes with it, but setting Grab And Move to the Windows key makes Alt yours alone.
- **An error sound with a shortcut.** Two remappers are changing the same keys. Turn off PowerToys Keyboard Manager (Cat Key can import its shortcuts first).

## Build from source

```bash
npm install
cargo test -p catkey-core          # the key engine's tests
npx tauri build                    # on Windows
python3 tools/library/build.py     # after editing the built-in library
```

The keyboard engine is a pure Rust crate (`crates/catkey-core`) with no operating-system code, so every timing case (Alt menus, key repeat, release order, missed releases) is covered by unit tests.
